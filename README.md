# کابینت سازی هنرور — وب‌سایت رسمی

وب‌سایت RTL، فارسی، ریسپانسیو و قابل استقرار روی GitHub Pages.

## اجرا
هیچ build step لازم نیست. فایل `index.html` را روی GitHub Pages منتشر کنید.

## ساختار
- `index.html` — ساختار و محتوای سایت
- `style.css` — طراحی، ریسپانسیو و کامپوننت‌ها
- `script.js` — منو، فیلتر نمونه‌کار، فرم رزرو و ارتباط سریع
- `assets/` — محل پیشنهادی برای تصاویر و لوگوی واقعی برند

## نکته تصاویر
تصاویر فعلی از Unsplash و برای نسخه نمایشی استفاده شده‌اند. برای نسخه نهایی می‌توانید تصاویر واقعی پروژه‌ها را داخل `assets/` قرار دهید و آدرس تصاویر را در HTML/CSS جایگزین کنید.
